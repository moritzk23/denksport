# Denksport 🧠

Eine minimalistische Trainings-App für **Mathe, Logik & Gedächtnis** – als installierbare Web-App (PWA), die offline läuft.

## Module
- **Kopfrechnen** – adaptives Rechnen auf Zeit
- **Zahlenreihen** – Muster erkennen und fortsetzen
- **Zahlen merken** – immer längere Ziffernfolgen
- **Logik-Schlüsse** – Aussagen als wahr/falsch bewerten
- **Muster-Matrix** – Regel im 3×3-Raster erkennen (IQ-Test-Stil)
- **N-Back** – Arbeitsgedächtnis-Training
- **Flow** – endloser Häppchen-Modus mit Combo & Leben

## Features
- Vier Themes (Graphit, Papier, Tinte, Sepia)
- Einstellbare Schwierigkeit oder mitwachsendes Level pro Modul
- Globales XP-/Level-System, Tages-Streak, Statistik
- Sound-Effekte, komplett offline-fähig
- Fortschritt wird lokal auf dem Gerät gespeichert

## Lokal starten
```bash
python3 -m http.server 8123
```
Dann `http://localhost:8123` im Browser öffnen.

## Auf dem iPhone installieren
Die veröffentlichte Adresse in Safari öffnen → Teilen → **„Zum Home-Bildschirm"**.

---
Einzelne HTML-Datei, kein Build-Schritt, keine externen Abhängigkeiten.
